# Rental Apartment Application

A modern, scalable full-stack real estate platform built with **Next.js**, **Node.js**, and **AWS**. This application enables users to browse rental properties, view detailed apartment information, and manage listings through a secure and high-performance cloud architecture.

## 🚀 Overview

This project demonstrates how to build an enterprise-grade Rental Apartment Application using modern web technologies and AWS cloud services. The application follows best practices for scalability, maintainability, security, and user experience.

## ✨ Features

* 🔐 Secure authentication and authorization with AWS Cognito
* 🏠 Browse and search rental apartment listings
* 📄 Detailed property pages with images and descriptions
* ❤️ Save favorite properties
* 📱 Responsive and mobile-friendly design
* ⚡ Fast server-side rendering and optimized performance
* ☁️ Cloud-native infrastructure powered by AWS
* 🎨 Modern and accessible user interface

* AWS Amplify
* AWS Cognito

## 🏗️ Architecture

The application follows a modern full-stack architecture:

* **Frontend** built with Next.js and TypeScript
* **Backend API** built with Express.js
* **Authentication** managed by AWS Cognito
* **Database** hosted on Amazon RDS
* **File Storage** handled through Amazon S3
* **API Management** using Amazon API Gateway
* **Deployment** powered by AWS Amplify and EC2

## 🔐 Authentication

User authentication and authorization are implemented using AWS Cognito, providing:

* User registration and login
* Secure JWT-based authentication
* Protected routes
* Session management
